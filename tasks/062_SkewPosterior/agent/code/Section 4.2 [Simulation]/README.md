### Simulation study: high-dimensional Poisson model [Section 4.2 of the main paper]

- `Simulation_Poisson_HD.R`. `R` script to reproduce the simulation study on the high-dimensional Poisson regression in Section 4.2.

- `Functions_Poisson_HD.R`. `R` script containing additional functions used in `Simulation_Poisson_HD.R`.

- `Gauss_EP_Poisson.R`. `R` script to obtain a Gaussian EP approximation under the high-dimensional Poisson regression model. 

- `Functions_approximations_and_godfit.R`. `R` script containing a collection of useful functions. 


All analyses were performed on a **MacBook Pro (macOS Sonoma 14.5)** using **R 4.5.1**.

**IMPORTANT:** Although a seed is set at the beginning of each routine, the final output may vary slightly depending on the versions of the `R` packages used. These differences arise from internal changes to certain functions across package updates. **However, the magnitude of these variations does not affect the final conclusions.**
