# xPatch

Official implementation of xPatch: Dual-Stream Time Series Forecasting with Exponential Seasonal-Trend Decomposition (AAAI 2025).

Upstream: https://github.com/stitsyuk/xPatch, commit `d12eecaa11409109582f5e2ffdebcc2cffd47b3e`.

The benchmark instructions are in the parent README. Run `train.sh` and `predict.sh` through the specified interfaces. The model is in `models/xPatch.py` and `layers/`; training and validation are in `exp/exp_main.py`.
