# three_lvl_cSMART_sim_study

This repository contains R code and supporting files for the simulation study of longitudinal data from a three-level clustered SMART. The code generates simulated data under the data-generative environments described in the paper, fits the corresponding analysis models, conducts inference, and produces publication-ready simulation tables.

The simulation workflow is organized around a driver file, `00_Notes/Driver_Three_Level_Simulations.xlsx`, which contains the data-generative parameters, simulation instructions, and analysis specifications. The `Dictionary` sheet in the driver file describes the fields and how they should be specified.

## Repository structure

``` text
three_lvl_cSMART_sim_study/
├── 00_Notes/
├── 01_Programs/
├── 02_Data/
├── 03_Analysis/
└── 04_Output/
```

## `00_Notes/`

This directory contains files that support the flow of the simulation study.

| File or directory | Description |
|----|----|
| `Driver_Three_Level_Simulations.xlsx` | Main driver file for the simulation study. It contains all data-generative parameters, simulation settings, and analysis specifications. The `Dictionary` sheet describes each field. Each row of the `main` sheet corresponds to a data-generative environment to simulate. |
| `Consistency_Check/` | Output from sanity checks assessing whether the data-generative code produces data with the intended marginal and conditional distributions. |
| `Pre_R_MC_Parameters/` | Monte Carlo estimates of pre-response conditional parameters. These parameters are generated by `01_Programs/Pre_R_Cond_Parm_MC.Rmd` and are used in the full data-generative model. As described in the simulation design appendix, they are needed to enforce the desired marginal and conditional consistency properties. |
| `Sim_Parms_From_ASIC/` | Parameters estimated from ASIC data. These are processed and adjusted for compatibility with the simulation data-generative model before being incorporated into the driver file. |
| `Model_Fitting_Wrapper.R` | User-facing wrapper functions for implementing the analysis model described in the paper for prototypical clustered SMARTs. These functions are included to make the method easier to use for external researchers. They are not used directly in the simulation code. |

## `01_Programs/`

This directory contains the R code that implements the simulations.

| File or directory | Description |
|----|----|
| `Preamble.R` | Loads common packages, universal variables, and other overhead code used across the simulation programs. |
| `Process_ASIC_Parms.Rmd` | Processes data-generative parameters obtained from analyses of the ASIC data under a range of conditions. The script reformats and lightly adjusts these parameters so that they align with the simulation data-generative process and can be incorporated into the driver file. This script is for parameter processing only. The processed parameters used in the simulations are already included in the main driver file. |
| `Check_Distribution_Consistency.Rmd` | Sanity check for the data-generative model. This script assesses whether the simulation code generates data with the intended marginal and conditional distributions. |
| `Pre_R_Cond_Parm_MC.Rmd` | Runs pre-response data generation and response simulation to estimate pre-response conditional means and variances by Monte Carlo. The resulting parameters are stored in `00_Notes/Pre_R_MC_Parameters/` and are used in the full data-generative model. |
| `Run_MC_Analysis.Rmd` | Runs the main Monte Carlo simulation analyses. This script reads the driver file, simulates data under the selected settings, fits the specified analysis models, conducts inference, and stores the resulting output. |
| `Create_Tables.Rmd` | Processes simulation results and creates publication-ready tables and other output. |
| `Create_Tables.html` | Rendered output showing additional simulation results and Monte Carlo confidence intervals. |
| `Functions/` | Helper functions for data generation, model fitting, and analysis. |
| `Alt_Sims/` | Code for alternate simulation settings with more than three time points. |

## `02_Data/`

This directory is set up to store raw output from each simulation iteration. It is intentionally kept empty in the repository because the full simulation output is large. When the simulations are run locally, raw model output should be written here.

## `03_Analysis/`

This directory is set up to store processed inference output. The simulation workflow first generates and stores raw model output, then processes that output to conduct inference. These inference results are stored in `03_Analysis/`. As with `02_Data/`, this directory is intentionally kept empty in the repository because the generated files are large.

## `04_Output/`

This directory is used for camera-ready output, including final simulation tables and other formatted results for publication.

## Simulation driver

The main source of simulation specification is:

``` text
00_Notes/Driver_Three_Level_Simulations.xlsx
```

This driver file contains the data-generative parameters for the simulation runs, as well as the instructions for data generation and model fitting. The `Dictionary` sheet describes the necessary fields. The `main` sheet contains the primary simulation settings, with each row corresponding to a distinct data-generative environment.

The processed ASIC-derived parameters used in the simulation study are already included in the driver file. The script `01_Programs/Process_ASIC_Parms.Rmd` documents how these parameters were processed, but it does not need to be rerun to reproduce the simulation analyses described in the paper.

## Running the simulations

To run the simulation analyses described in the paper:

1.  Download the repository files, including the pre-response Monte Carlo parameters in `00_Notes/Pre_R_MC_Parameters/`.

2.  Open `00_Notes/Driver_Three_Level_Simulations.xlsx`.

3.  Set the relevant `run_simulations` flag in the driver file from `0` to `1`.

4.  Run:

``` text
01_Programs/Run_MC_Analysis.Rmd
```

This script simulates data, fits the specified models, conducts inference, and stores the resulting output.

5.  Run:

``` text
01_Programs/Create_Tables.Rmd
```

This script processes the simulation results into tables and other publication-ready output. Before running it on a new machine, check that the script reads in the correct local output files. The current version refers to the local names of stored simulation output, so file paths or names may need to be updated after rerunning the simulations.

## Regenerating pre-response Monte Carlo parameters

The repository includes the pre-response Monte Carlo parameters needed for the simulation analyses in the paper. To regenerate these parameters from scratch:

1.  Specify the pre-response variance structure in the `var_parm_settings_pre_r` sheet of `00_Notes/Driver_Three_Level_Simulations.xlsx`.

2.  Run:

``` text
01_Programs/Pre_R_Cond_Parm_MC.Rmd
```

This script calculates and stores the pre-response conditional parameters in `00_Notes/Pre_R_MC_Parameters/`.

3.  Specify the overall mean structure, variance structure, and model-fitting specifications in the `main` sheet of the driver file. This may require specifying distributions in the `cond_param_settings`, `var_parm_settings_pre_r`, and `var_parm_settings_post_r` sheets.

4.  Run `01_Programs/Run_MC_Analysis.Rmd` to generate simulation and inference output.
